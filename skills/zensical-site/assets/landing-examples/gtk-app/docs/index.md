## Features

<div class="grid cards" markdown>

- :lucide-file-text:{ .lg }

    **Plain files**

    Notes are Markdown files in a folder you choose, so any editor, sync tool or backup can read them.

- :lucide-search:{ .lg }

    **Instant search**

    Type a few letters and every matching note appears, ranked by title first and then by content.

- :lucide-moon:{ .lg }

    **Light and dark**

    Follows the system style and accent colour, and adapts its layout from a phone to a wide desktop.

- :lucide-keyboard:{ .lg }

    **Keyboard first**

    Every action has a shortcut, listed in the shortcuts window, and focus never gets lost between panes.

</div>
